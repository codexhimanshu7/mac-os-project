# 🖥️ macOS Portfolio Web Application

A modern, interactive, and responsive macOS-themed portfolio web application built using **React** and **Tailwind CSS**. This project mimics the macOS desktop UI experience with custom draggable app windows, a functional interactive terminal, a integrated Spotify music player widget, and direct access to developer information.

---

## Features

- 💻 **macOS Desktop Interface:** Realistic macOS UI complete with top menu bar, dynamic status indicators, and an interactive dock with bouncing/hover effects.
- ⚡ **Interactive Terminal (zsh simulator):**
  - Custom terminal commands like `about`, `skills`, `projects`, `contact`, `github`, `resume`, and `echo`.
  - Type `help` to list all available commands.
- 🎵 **Spotify Music Integration:** Embedded Spotify widget to play background music seamlessly while browsing.
- 📄 **Integrated Resume Viewer:** Built-in PDF/document reader window to view developer experience and qualifications.
- 📁 **App Windows:**
  - Dynamic window management (open, minimize, maximize, and close controls).
  - Code editor view showing portfolio configurations.


---

## 🛠️ Tech Stack

- **Frontend Library:** React.js
- **Styling:** SCSS/ CSS Modules
- **Icons:** Lucide React / React Icons
- **Build Tool:** Vite

---
## ⌨️ Terminal Commands Overview

| Command | Description |
| :--- | :--- |
| `about` | Displays personal background information |
| `skills` | Lists technical skills and core tech stack |
| `projects` | Highlights featured projects and works |
| `contact` | Displays contact email and social links |
| `github` | Links directly to GitHub profile |
| `resume` | Opens developer resume |
| `clear` | Clears the terminal screen |
